# Roboface 부품 구매 리스트

라즈베리파이 기반 Stack-chan 스타일 AI 캐릭터 로봇 제작용 부품 리스트.

원본 참고: [M5Stack Stack-chan](https://docs.m5stack.com/en/stackchan)

---

## 1. 핵심 보드 ✅ 확정

| 부품 | 모델 | 가격대 (KRW) | 비고 |
|---|---|---|---|
| **메인 SBC** | **Raspberry Pi 5 (8GB)** | 약 160,000 ~ 180,000 | 로컬 Whisper + 소형 LLM 여유 |

### 필수 부속품 (Pi 5 전용)
| 부품 | 가격대 | 필수도 |
|---|---|---|
| **공식 5V/5A USB-C PD 어댑터** (27W) | 약 18,000 | 필수. 일반 어댑터는 전류 제한 걸림 |
| **Argon Poly+ 5 케이스 (블랙)** ⭐ | 약 28,000 ~ 35,000 | 필수. 케이스 + 액티브쿨러 일체형 |
| microSD 64GB A2 (SanDisk Extreme 등) | 약 15,000 | 필수 |
| **CSI 카메라 케이블 (미니 15핀 → 표준 22핀)** | 약 5,000 | 카메라 사용 시 필수. Pi 5는 미니 커넥터 |

### Argon Poly+ 5 특징
- 케이스 + 팬 + 히트싱크 통합 (별도 액티브쿨러 불필요)
- 상단 커버 분리 시 GPIO 전체 접근 가능
- 상단에 GPIO 핀맵 인쇄 → 배선 편의
- Pi 5 풀로드에서도 70°C 이하 유지

⚠️ LCD/서보/오디오 등 GPIO 연결 시 **상단 커버를 열어두고 사용**해야 함.

### 선택 부속품
- NVMe SSD + PCIe HAT — 부팅 속도 향상, 약 50,000~80,000원 (1차 제작 생략 권장)

## 2. 디스플레이 (얼굴) ✅ 확정

| 부품 | 스펙 | 가격대 |
|---|---|---|
| **Waveshare 2.4" LCD Module** | 240×320, ILI9341, 4-wire SPI, TFT | 약 12,000 ~ 18,000 |

### 선택 이유
- **해상도 240×320 = Stack-chan 원본 동일** → 오픈소스 얼굴 코드 재사용 가능
- **ILI9341 드라이버** = 라즈베리파이에서 가장 검증된 LCD 드라이버
- **양쪽 핀헤더** = 점퍼선 연결 매우 쉬움
- **나사 구멍 4개** = 케이스 마운트 용이
- 면적 약 37×49mm (1.69"의 1.6배) — 표정 표현 충분

### 주의
- TFT 패널이라 시야각이 IPS보다 좁음 → **정면 데스크탑 용도라면 무관**
- 동작 전압 3.3V만 (Pi 5 GPIO와 일치, 문제 없음)

### 핀 연결 (Pi 5 GPIO)
| LCD 핀 | Pi 5 GPIO (BCM) | 물리 핀 |
|---|---|---|
| VCC | 3.3V | 1번 |
| GND | GND | 6번 |
| DIN (MOSI) | GPIO 10 | 19번 |
| CLK (SCK) | GPIO 11 | 23번 |
| CS | GPIO 8 (CE0) | 24번 |
| DC | GPIO 25 | 22번 |
| RST | GPIO 27 | 13번 |
| BL (Backlight) | GPIO 18 | 12번 |

## 3. 구동부 (목/머리 움직임) ✅ 확정

| 부품 | 모델 | 수량 | 가격대 |
|---|---|---|---|
| **서보 모터** | **SG92R 마이크로 디지털 서보 (270°)** | 2개 | 개당 5,000 ~ 8,000 |
| **PWM 드라이버** | **[Voltly] PCA9685 16채널 PWM I2C 서보드라이버 (VLT-MD032)** | 1개 | 약 8,000 ~ 10,000 |
| 점퍼 케이블 | 듀퐁 암-암, 암-수 세트 | 1세트 | 5,000 |

### SG92R 선택 이유
- **디지털 제어** → 위치 유지력 우수, 응답 속도 빠름
- **토크 2.5kg·cm** → SG90보다 40% 강함, 머리 무게 충분
- **270° 회전** → 충분한 가동 범위
- 무게 약 9g (가벼움)

### ⚠️ 코드 주의사항
SG92R은 270° 서보라 PWM 펄스 폭이 표준 180°와 다릅니다:
```python
# adafruit-circuitpython-servokit 사용 시
kit.servo[0].set_pulse_width_range(500, 2500)
kit.servo[0].actuation_range = 270
```

### 안전 가동 범위 (소프트웨어 리밋)
- **X축 (Pan, 좌우)**: -90° ~ +90° (총 180°)
- **Y축 (Tilt, 상하)**: 5° ~ 85° ← 끝단 고착 방지 필수

### PCA9685 핀 연결 (Pi 5 GPIO)
| PCA9685 핀 | Pi 5 GPIO | 물리 핀 |
|---|---|---|
| VCC | 3.3V | 17번 |
| GND | GND | 9번 |
| SDA | GPIO 2 (I2C SDA) | 3번 |
| SCL | GPIO 3 (I2C SCL) | 5번 |
| V+ (서보 전원) | **태영전자 5V 2A SMPS 어댑터** ✅ | DC 5.5×2.1mm |

### ⚠️ 어댑터 2개 구분
| 어댑터 | 용도 | 사양 | 단자 |
|---|---|---|---|
| 1️⃣ Pi 5 본체용 | Pi 5 메인 전원 | 5V / 5A (27W) | USB-C |
| 2️⃣ **태영전자 SMPS** | PCA9685 서보 전원 | 5V / 2A | DC 5.5×2.1mm |

## 5. 카메라 ✅ 확정

| 부품 | 모델 | 가격대 |
|---|---|---|
| **카메라 모듈** | **Raspberry Pi AI Camera** (IMX500 + RP2040 탑재) | 약 90,000 ~ 110,000 |
| **Pi 5 카메라 케이블** | 22핀 ↔ 15핀 FFC, **300mm (30cm)** | 약 5,000 ~ 8,000 |

### 사양
- **Sony IMX500** Intelligent Vision Sensor (1200만 화소 + 온칩 NPU)
- **RP2040** 코프로세서 (AI 모델 펌웨어 관리)
- **온센서 AI 추론** — MobileNet, YOLOv8n 등 카메라 자체에서 실행
- 출력: 이미지 + 인식 결과(바운딩 박스/라벨)

### AI Camera 선택 이유
- **CPU 부담 0** → Pi 5는 LLM/대화/디스플레이에 집중
- **항상 켜진 얼굴 추적** 가능 (저전력, 발열 없음)
- 일반 카메라로도 사용 가능 (OpenCV에 그냥 이미지 입력 OK)
- 미래 확장성 (LLM에 영상 인식 결과 연계 가능)

### ⚠️ 학습 곡선
- 일반 picamera2 외에 **`imx500` 라이브러리** 추가 학습 필요
- 커스텀 AI 모델 사용 시 **`.rpk` 포맷 변환** 필요 (TensorFlow → IMX500)
- 1차 제작에선 **사전 빌드 모델 (얼굴 인식, 객체 탐지)** 그대로 사용 권장

### 활용 단계 (점진적 추가)
1. 1차: 카메라 없이 얼굴/움직임/대화 완성
2. 2차: AI Camera 사전 빌드 얼굴 인식 모델 → 사람 따라 머리 회전
3. 3차: 커스텀 AI 모델 학습/배포 (사용자 식별, 제스처 인식 등)

### ⚠️ Pi 5 전용 케이블 별도 필요
Pi 5는 CSI 커넥터가 미니 22핀으로 변경됨. Camera Module 3 동봉 케이블(15핀)은 호환 안 됨.

검색어:
```
"라즈베리파이5 카메라 케이블 22핀"
"Pi 5 camera cable 22pin"
```

### 활용 단계 (점진적 추가)
1. 1차 제작: 카메라 없이 얼굴/움직임/대화 완성
2. 2차: 얼굴 인식으로 사람 따라 머리 회전
3. 3차: 환경 인식 (LLM에 이미지 입력)

## 6-1. 센서 ✅ 확정

| 센서 | 모델 | 용도 | 가격 | 인터페이스 |
|---|---|---|---|---|
| **모션 (레이더)** | **S3KM1110 24GHz mmWave 인체 미세 동작 감지** | 정적 존재 + 미세 움직임 감지 (호흡 등) | 5,790 | UART (GPIO 14/15) |
| **온습도** | DHT22 모듈 (3핀, PCB형) | 환경 대화 소재 | 5,000~8,000 | GPIO 22 (1-Wire) |

### ⏳ 추후 추가 검토 (1차 제작에서 제외)
| 센서 | 이유 | 비고 |
|---|---|---|
| TTP223 터치 | 부품 없음 | mmWave + IMU로 일부 대체 가능 |
| MPU6050 IMU | 1차 핵심 아님 | 로봇 자기 인식(들어올림/기울임)에 필요. 추후 추가 |

### DHT22 주의
**3핀 모듈 형태**로 구매 (4핀 베어 센서 아님). 풀업 저항 내장형이 작업 편함.

### 행동 매핑 예시
| 센서 입력 | 로봇 반응 |
|---|---|
| mmWave 신규 감지 | 고개 돌려 인사 |
| mmWave 정적 존재 (사용자 책상 곁) | 가끔 자발적 멘트, 표정 변화 |
| mmWave 사라짐 (자리 비움) | 슬픈 표정, 대기 모드 진입 |
| mmWave 거리 가까움 | 적극 반응, 표정 큼 |
| DHT22 고온고습 | "후덥지근하네요" 자발 코멘트 |
